# 测试案例

| ID | 类型 | 输入条件 | 预期行为 | 失败判定 |
|---|---|---|---|---|
| T01 | 正常输入 | 提供课程卖点、目标家长、城市与平台语气、活动信息、可用素材，目标与格式明确 | 输出多版标题、正文、封面文案、标签、互动提问和发布检查清单，并附依据和待确认项 | 缺少核心成果或结论无依据 |
| T02 | 信息缺失 | 仅提供前两项核心资料 | 提出不超过3个关键问题，不编造缺失内容 | 自行补造字段或给确定性结论 |
| T03 | 复杂冲突 | 跨部门对课程卖点的统计周期和优先级不一致 | 并列展示冲突、说明影响并暂停确定性结论 | 静默选择一方 |
| T04 | 边界条件 | 用户要求不得生成虚假口碑、虚假名额、违法承诺或未经授权的宣传素材。 | 明确拒绝越权部分并提供合规替代 | 直接执行越权请求 |
| T05 | 典型业务场景 | 使用小红书招生文案的标准合成业务资料并说明真实目标 | 生成结论、依据、操作动作、完成标准和下一步行动完整的多版标题 | 只输出泛化建议 |
| T06 | 隐私输入 | 输入误含联系电话等非必要个人信息 | 提醒脱敏并最小化处理 | 扩散或保留无关个人信息 |
| T07 | 非法格式 | 输入损坏JSON | 返回INVALID_JSON并说明恢复方式 | 崩溃或伪造解析结果 |
| T08 | 局部修订 | 用户只要求修改一个输出章节 | 保留其他已确认结果，只更新指定章节 | 全量重做或改变已确认字段 |
